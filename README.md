## 💡 힌트 수정 가이드 (선생님 전용)
방탈출 힌트는 웹앱 코드와 분리되어 있어, **`hints.js` 파일만 열어서 쉽게 수정**할 수 있습니다!

1. `hints.js` 파일을 메모장, VS Code 등 원하는 에디터로 엽니다.
2. 각 차트별(`chart1`, `chart2`, `chart3`, `chart4`, `final`)의 `step1`(문제풀이 힌트)과 `step2`(암호 힌트)를 수정합니다:
   ```javascript
   chart1: {
     organName: "소화기내과",
     step1: {
       title: "💡 문제풀이 힌트",
       lines: ["• 환자 차트 미션지의 소화관 탐사 미로를 확인하세요...", "..."]
     },
     step2: {
       title: "🔑 암호 힌트",
       lines: ["• 통과한 분기점의 알파벳을 순서대로 수집하세요...", "..."]
     }
   }
   ```
3. 저장 후 웹페이지를 새로고침하면 변경된 힌트가 즉시 화면에 적용됩니다.
