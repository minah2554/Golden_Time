## 📌 프로젝트 개요
- **앱 명칭**: GOLDEN TIME MEDICAL CENTER (골든타임 메디컬 센터 방탈출)
- **대상**: 중학교 2학년 과학 (1반 ~ 6반)
- **단원**: 소화, 순환, 호흡, 배설 (동물과 에너지)
- **제한 시간**: 35분 (골든타임)
- **진행 방식**: 웹 인터랙티브 바이오 모니터링 시스템 + 오프라인 환자 차트 미션지/포스터 하이브리드
- **배포 버전**: `v1.2` (MINARI STUDIO Footer 탑재)

1. **병원 메디컬 로고 아이콘 전면 일괄 적용**:
   - 웹사이트 파비콘 (`<link rel="icon">`, `<link rel="shortcut icon">`, `<link rel="apple-touch-icon">`)
   - 상단 헤더 브랜드 로고 (`<header>` 영역)
   - 타이틀 아이콘 (`#board-title` 옆 및 메인 화면 타이틀 옆)
   - 하단 푸터 브랜드 로고 (`<footer>` MINARI STUDIO 옆)
2. **정답 분리 설정 파일 탑재 ([answers.js](file:///d:/바이브%20코딩/중2%20소화%20온오프라인%20방탈출/골든타임%20메디컬센터%20방탈출/answers.js))**:
   - 정답을 코드 수정 없이 `answers.js`에서 언제든 수정 가능
   - 단일 고유 정답 엄격 검증 (중복/유사 정답 불가)
   - **소화계**: `펩신`
   - **순환계**: `4129`
   - **호흡계**: `8522`
   - **배설계**: `3709`
   - **최종 해독**: `3817`
3. **교사 관리자 모드 고도화 (`admin1234`)**:
   - **💡 힌트 열람 횟수 추적**: 모둠별로 힌트를 몇 회 열람했는지 실시간 카운트
   - **⏱ 미션 완료 소요 시간**: 골든타임 35분 중 완치까지 걸린 실제 시간(분/초) 자동 기록
   - **🔄 모둠 데이터 개별 리셋**: 잘못 접속한 모둠의 진행 데이터를 원격에서 즉시 초기화
4. **학생 화면 팀 재선택 리셋 버튼**:
   - 반이나 모둠을 잘못 선택해 접속했을 때 즉시 초기화하고 다시 로그인할 수 있는 헤더 버튼 탑재
5. **학급 선택 최적화**:
   - 1반부터 6반까지만 깔끔하게 선택하도록 드롭다운 정비

## 🔑 정답 설정 가이드 ([answers.js](file:///d:/바이브%20코딩/중2%20소화%20온오프라인%20방탈출/골든타임%20메디컬센터%20방탈출/answers.js))
선생님께서 정답을 변경하고 싶으실 경우, [answers.js](file:///d:/바이브%20코딩/중2%20소화%20온오프라인%20방탈출/골든타임%20메디컬센터%20방탈출/answers.js) 파일의 값을 수정하시면 즉시 적용됩니다:
```javascript
window.GAME_ANSWERS = {
  chart1: "펩신",  // 소화계 정답
  chart2: "4129",  // 순환계 정답
  chart3: "8522",  // 호흡계 정답
  chart4: "3709",  // 배설계 정답
  final:  "3817"   // 최종 마스터 해독 코드
};
```
