## 💡 힌트 수정 가이드 (선생님 전용)
방탈출 힌트는 웹앱 코드와 완전히 분리되어 있어, **`hints.js` 파일만 열어서 쉽게 수정**할 수 있습니다!

1. `hints.js` 파일을 메모장, VS Code 등 원하는 텍스트 에디터로 엽니다.
2. 각 차트별(`chart1`, `chart2`, `chart3`, `chart4`, `final`) 힌트 제목과 내용을 수정합니다:
   ```javascript
   chart1: {
     organName: "소화기내과",
     step1: {
       title: "💡 1단계 힌트: 소화효소란?",
       lines: [
         "• 위에서 분비되는 소화효소: 펩신(pepsin)",
         "..."
       ]
     },
     step2: { ... }
   }
   ```
3. 저장 후 웹페이지를 새로고침하면 변경된 힌트가 즉시 화면에 적용됩니다.
